2026-08-29

决赛 + IChO 真题入库，题量 283 → 526

NEW

题库不再只有国初真题。本次新增 CChO 决赛与 IChO 理论真题，全部带考点挂载，可检索、可筛选、可加入组卷篮。

  • 新增题量：决赛真题 110 题、IChO 理论真题 133 题，合计题库达 526 题
  • 考点挂载：新题全部挂到考纲，与初赛共通的考点落在通用编号上，用初赛考点检索同样能找到决赛题
  • 来源分色：题卡角标按来源区分，决赛为绿色、IChO 为紫色，一眼可辨
  • 筛选项：来源筛选新增 IChO真题
  • 考察频率口径：频率统计与年份趋势只计国内真题（初赛 + 决赛），IChO 可检索可筛选但不计入频率，避免国际赛题拉偏国内复习参考
  • 搜索修复：修掉一处长期存在的字段名错误，此前题干正文实际未进入搜索索引，现已全部纳入

IChO 部分答案为英文原文，中文翻译暂时缺失；少量题目暂无答案或分值，均已在题面标注。

2026-08-26

修正两处题干数据错误

数据

感谢教练通过反馈按钮报错，两处题干录入错误已修正。

  • 2018 国初第 1 题 1-3：原录入为「单质磷与过量 NaBH₄ 反应制备硼氢化钠」，与原卷不符且逻辑不通（NaBH₄ 是反应物不是产物）。已按原卷改为「单质碲与过量 NaBH₄ 反应制备碲氢化钠」
  • 2002 国初第 5 题：组成分析中 M 的质量分数原录入 31.68%，与原卷及标准答案的推导（58.7 g/mol → Ni）矛盾。已改为 21.68%
  • 2018 国初第 5 题 5-2 新增「原卷勘误提示」：该题 Lu / Hf 同位素质量数确有错误，但错在 2018 年原卷本身（官方答案已红字承认「误将 ¹⁷⁶Lu/¹⁷⁷Hf 写作 ¹⁷⁷Lu/¹⁷⁷Hf，导致本题无法求算」）。题干正文保持原卷原样，题后新增编者注说明正确同位素、官方两种给分办法及岩石年龄 5.06×10⁸ 年

另已对全部 283 道题做了一轮计量自洽性体检（元素百分数反推、天然同位素质量数、产物/反应物逻辑、中文元素名↔符号一致性、跨源数字比对），未发现其他同类错误。

NEW

  • 组卷篮子存在本机浏览器中，也不受影响
  • 此前的登录记录与浏览历史无法迁移，敬请谅解
2026-07-07

组卷全选 + 修复部分题目题干空白

NEW

两处改动：一个新功能，一个 bug 修复。

  • 组卷一键全选：主视图工具栏和搜索面板筛选条各多了一个按钮。当前筛选下的题目一键全部加入组卷，再点一次全部移出。按钮实时显示 已加入 / 总数，全部加入时变琥珀色提示可移出
  • 修复部分题目题干不显示：某些题目打开后题干区域空白、只有答案和解析可见的问题已修好
2026-06-17

题图 / 解析图全部支持点击放大

NEW

题干和解析里的图都可以点击放大查看了。之前只有题目缩略图能放大，解析图压在原位看不清的问题修复。

  • 打开后默认按视窗适配，再点一次切到原始尺寸看长图细节
  • 顶部工具栏：🔍 切换尺寸 / ↗ 新窗口（兜底超长解析图）/ × 关闭
  • 键盘：F 切尺寸、ESC 关闭、点遮罩外侧也关
  • 覆盖范围：题目缩略图、题干 Markdown 内插图、答案解析插图，统一处理
2026-06-13

组卷一键下载 PDF

新功能

组卷生成的试卷现在可以一键下载 PDF，所有浏览器通用，包括夸克 / UC / 微信内置等阉割了系统打印的环境。

  • 组卷预览右上角新增 📥 下载 PDF 主按钮（推荐）
  • 原 🖨 打印 按钮保留作为备用，走浏览器打印对话框
  • 下载 PDF 走服务端生成，5-15 秒后浏览器弹原生下载，文件名自动带学校 + 日期
  • 失败会自动询问要不要回退到打印对话框
