上手 6 步

和首页氢松小助手讲的是同一套，纸面版方便随时查。

注册并登录账号

顶栏右上角点 登录 / 注册。看题、组卷、提交反馈这些核心功能都需要登录账号。游客可见目录和题目标题，但展开题干、加入篮子、生成试卷都会被拦。

入口：顶栏右上 · 登录按钮

用搜索框找东西

左上角搜索框能搜考点关键词（如 氧化 晶胞）、题号（如 CCO38-08）、甚至化合物名（如 二茂铁）。出题遇到生词最先来这。

锚点：#search

看左侧考纲目录

左侧是按官方 8 大模块组织的考纲目录。点任一节点，中栏会展开该考点的关键词列表、相关例题、考察频率柱状图。

锚点：#tree

读中栏题卡

中栏是考点详情。蓝色左边框的题卡是这个考点挂的真题。点开看完整题干、答案、以及每道题对应的教材原文片段（橙色 chip 是命中教材的关键词，点击弹原文）。

锚点：#colM

勾选题目进组卷篮

每张题卡左上角勾选框加入篮子。底部组卷篮显示已选数量，点开能拖拽排序、批量预览、一键生成试卷。生成的试卷自动重排题号、含答案/解析、可切学生模式藏答案。

锚点：#basketBar

生成卷 → 下载 PDF / 打印

组卷完成点 📋 生成卷，会在当前页全屏铺开试卷预览。右上角有两个按钮：

  • 📥 下载 PDF（推荐）：服务端直接生成 PDF 给浏览器下载，一键完事。所有浏览器都通用，包括夸克 / UC / 微信内置等不支持系统打印的环境。生成耗时约 5-15 秒，请耐心等待。
  • 🖨 打印（备用）：走浏览器原生打印对话框，可在打印机或"另存为 PDF"虚拟打印机里手动选择。手机端会弹引导卡走系统"分享 → 打印"。

如果"下载 PDF"出错，会自动询问要不要回退到打印对话框。

配套：组卷篮底栏

常见问答

遇到这些情况通常不是 bug。

为什么点题目卡片没反应？

大概率是没登录。游客可看目录、题目标题、考察频率，但展开题干、加篮、生成卷、提交反馈都需要登录账号——这是为了保护题库内容。

顶栏右上角点 登录 / 注册，邮箱注册即可，无需邮箱验证。

教材链接点了打不开 PDF？

在线版没托管教材 PDF 文件（12 本现役教材合计 1.17 GB，超出托管平台单文件 25 MB 限制）。点击教材链接显示的是页码定位卡——告诉你这个知识点在哪本书的第几页。

请配套纸质书或自己保存的电子版翻阅。常用教材：Clayden 有机、严宣申无机、Housecroft、武大无机分析、徐光宪结构化学、Atkins 物化、傅献彩物化等。

组卷生成的 PDF 在手机上保存不了？/ 夸克浏览器没法另存 PDF？

首选：直接点 📥 下载 PDF 按钮。这条路径走服务端生成，所有浏览器通用，包括夸克 PC / 夸克手机 / UC / 微信内置浏览器这些阉割了打印功能的环境。生成需要 5-15 秒，浏览器会弹原生下载弹窗。

如果非要走"🖨 打印"按钮：

  • iOS Safari：弹引导浮层 → 走系统分享 ⬆️ → 打印 → 双指放大 → 存储到文件
  • Android Chrome：浏览器菜单 ⋮ → 打印 → 另存为 PDF
  • 夸克 / UC：菜单里找不到"打印"，只能走"📥 下载 PDF"
  • 微信内置浏览器：右上角 ··· → 在浏览器中打开，再走打印

桌面版直接走 📥 下载 PDF 最省事；想看预览/调页边距就用 🖨 打印。

题目里的化学式显示成乱码？

页面用 KaTeX 渲染所有化学式（$\ce{H2SO4}$）和数学公式。如果偶现乱码：

  • 刷新一次页面（Ctrl/Cmd + R），KaTeX 资源可能没加载完
  • 个别老题的 OCR 可能漏标，用右下角 💬 反馈贴个题号给作者
搜索结果排序怎么定的？

三栏并排：题目 / 考点 / 教材，每栏内默认按相关性 + 年份倒序。题目栏可切换"按年份倒序 / 按命中度"，每栏限制最多 30 条以保流畅。

搜不到的话，试试缩短关键词到 2-4 字，或换近义术语（如"晶胞" / "晶格" / "密堆积"互查）。

怎么知道某考点近年考没考过？

点开任意考点 → 中栏滚到底有考察频率 / 趋势卡片：

  • 26 届柱状图（每年命中题数）
  • 四级标签：高频（≥70%）/ 中频（≥40%）/ 低频（≥15%）/ 冷门
  • 三向趋势：上升 / 稳定 / 下降（前后两段平均比对）
  • "最近 5 届中 N 届涉及"——命题选材最直接的指标
能不能下载离线版？

暂时只发布在线版（Cloudflare Pages）。离线版本是 考纲速查_v6.html 单文件 16 MB + 配套图片目录共 80+ MB，主要给作者本地用，未来如有需求会发 zip 包。

如果常用，建议直接收藏 https://h-teamsyllabus.pages.dev/ 到浏览器主屏。

为什么不显示 CCO40 / 缺哪一届？

当前在线版收录 CCO14-39 共 26 届（其中 2022 年 CCO36 那届首次入库于 2026-06-06）。CCO40 等新届会在赛季结束后陆续补入。

如发现哪一届题号断档（如 CCO38 跳号），用 💬 反馈告诉作者。

怎么再次看一遍氢松小助手的引导？

右下角 ❓ 帮助 按钮（蓝色圆形 FAB，💬 反馈按钮上面）随时点开重走 6 步。

或在浏览器控制台执行 HSongTour.reset() 清掉首访标记，下次刷新会自动弹。

数据有错误怎么办？

右下角 💬 反馈按钮，选"题目错误"类型，写题号 + 简短描述（如 CCO38-04 Q3 答案疑似漏算）。会直达作者飞书群，通常 1-2 天内响应。

不需要登录飞书，反馈也不会暴露你的任何隐私。
