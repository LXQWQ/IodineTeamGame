📖 化境争霸 · 规则说明

🎯 胜利条件

满足以下任一条件即获胜：

  • 占领过半：控制超过 61 个六边形格子（全场121格的半数以上）
  • 首都陷落：攻陷对方首都（左上角红方首都、右下角蓝方首都）

🔵 回合流程

每回合分为三个阶段：

  • 资源阶段：每格+2资源，首都+3，极端pH/电势格额外产出。每个驻军单位消耗1资源/回合维护费
  • 部署阶段：从底部面板选择单位，点击己方领地或接壤中立格部署。每回合最多部署2次，也可直接结束
  • 反应阶段：自动检测所有相邻的敌对单位对，按化学规则结算胜负

🧪 酸碱模式

  • 酸方（红）部署酸单位，碱方（蓝）部署碱单位
  • 相邻敌对单位触发中和反应：有效力量 = 基础power + |pH-7|×0.5
  • 每个格有pH值(0-14)，被酸占领降pH，被碱占领升pH
  • pH=7的格子自动归为灰色中立

⚡ 电化学模式

  • 阳极（橙）vs 阴极（青），比较 基础power + |potential|
  • 每个格有电势值，占领后电势朝己方方向

⚛️ 元素争霸

  • 碱金属（红）vs 卤素（绿），反应查元素反应表
  • 随机散布野元素格(C/O/N/惰性气体)，提供地形加成或减益

🧠 AI难度

  • 简单：随机选择合法落子
  • 中等：贪心算法，选当前收益最高的位置
  • 困难：2层minimax，预判你的回应后选最优
