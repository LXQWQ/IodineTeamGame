怎么玩

目标：把左边的分子，变成右边那个，步数越少越好。

一步＝选一张反应卡。卡上会写清可用条件和变化，写着「不可用」的卡片会告诉你缺什么官能团。

分子由四件事描述：碳数、官能团（-OH 羟基 / =O 羰基 / -CHO 醛基 / -COOH 羧基 / -COO- 酯基 / -O- 醚键 / -X 卤素）、碳碳双键数、环。

评级：达到最少步数 → ⭐⭐⭐；多 1 步 → ⭐⭐；再多 → ⭐。
